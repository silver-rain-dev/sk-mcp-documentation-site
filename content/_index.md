## What are MCPs?

The [**Model Context Protocol**](https://modelcontextprotocol.io/docs/getting-started/intro) is an open standard that lets AI assistants (Claude, Cursor, VS Code Copilot, and others) connect to external tools and data sources. MCP servers act as bridges — they expose structured tools that AI agents can call to read, write, and interact with professional software.

**No coding required.** You describe what you want in plain language, and the AI agent uses the appropriate MCP tools to get it done.
