AI-powered Wwise authoring through the Model Context Protocol.

SK Wwise MCP is a modular suite of MCP servers that lets AI agents interact with **Audiokinetic Wwise** — the industry-standard audio middleware for games. It exposes **95 tools** across **12 servers**, covering everything from browsing objects to generating SoundBanks.
